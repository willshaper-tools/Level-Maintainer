# Level Maintainer Config List

An unofficial web page for building the `config.lua` entries of the [Level Maintainer](https://github.com/Willshaper/Level-Maintainer), an OpenComputers program for the Minecraft modpack GT New Horizons.

**Open it:** https://willshaper-tools.github.io/Level-Maintainer/

It is a single `index.html` with no build step. Lists are saved in your browser only; the page doesn't send anything you enter anywhere. See the [Level Maintainer README](https://github.com/Willshaper/Level-Maintainer#config-list-web-page) for how to use it.
